## Rulings and overturn conditions

1. **Unbound named clears remain named refusals.** The census’s DSA-delete scenario is actually unbound (it binds framebuffer 0 before the call), on both backends. The bound named case crosses and renders in the new pixel cases. No server rebind workaround: Espryt’s barrier-pulled binding would undo it. Overturn with an integrator-authorized handle-keyed backend binding path (P7/P3b/P4b); the contract’s optional stretch is not required to report this next blocker.
2. **Depth-copy wrong-answer failures are next-round work.** All three measured variants now execute the copy and reach `CopyTexImageFromADepthAttachmentSurvivesAReadBack`; all 3072 values read as zero. Color image/sub-image copy pixel controls pass. No claim that depth copies render correctly; fixes outside the granted emitter/sink boundary are requested from the integrator. Overturn by a depth-copy/readback fix making those same assertions pass.
3. **Read-attachment-only depth/stencil inspection remains a next blocker.** `AReadAttachmentOnlyTexturesDepthStencilModeReachesTheDriver` reaches its inspection assertion; it is no longer stopped at ClearBufferfi. The focused fi test verifies both actual depth and stencil values. Overturn with a fix to the applied-mode observation/state path, validated against that scenario.
4. **No mip-storage re-derivation was needed.** Both measured mip cases pass, as does a generated-level pixel control. Existing `generate-mipmap-storage` and `generate-mipmap-cpu-fallback` refusals remain intact. Overturn if a measured format reaches them; only the descriptor-derived storage site is granted, CPU writeback still needs P8/P9.
5. **No `+RENDERBUFFER` refusal is added to framebuffer-sourced copies.** The source is the read framebuffer, which may legitimately have a renderbuffer attachment. The contract’s explicit resource-endpoint `CopyImageSubData+RENDERBUFFER` refusal belongs to i1, not f1. Overturn only by a contract revision for these two slots.
6. **Existing codec arms suffice.** Clear (57), generate_mipmap (54), framebuffer copy (76) already decode their PODs and invoke the corresponding sinks; live peer cases prove fields survive that path. No codec layout changes were necessary. Overturn with a newly measured payload shape requiring a contract change.
7. **Partition arithmetic is additive.** f1 moves 11 slots; counts on this base are A=2/B=16/C=53. The old global `C==64` assertion becomes `B+C==69`, retaining all per-owner asserts. Integrator must add the other packages’ counts in the shared RemoteClient partition test.
