## 目标

Android 上的 server 应用自己开一个全屏窗口，把收到的渲染流直接画到屏幕上；client 不需要有窗口（完全无头）。窗口没了（比如按 HOME）时，client 干净地得到"设备丢失"，server 继续等下一个连接。
