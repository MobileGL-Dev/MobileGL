New `testdata/split_private_log_smoke.sh` checks the private-file cases and their exact failure messages. `split_negative_controls.sh --self-test` runs both the existing smoke suite and this extension.

Only the six granted source/test files changed. No workflow or local gate edits were needed: both existing call sites discover paths automatically. No new dependency on the temporary CI branch trigger. No C++ changes, generated opcode/catalogue changes, LFS fetch, or adb access.
