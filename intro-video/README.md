# MobileGL videos

Sources for two promotional videos. Rendered output, audio and downloaded fonts are not committed (see
`.gitignore`); each folder has a `fetch_fonts.py` and a README with the exact render steps.

| folder | video |
|---|---|
| [`paper/`](paper/README.md) | **MobileGL intro**: a ~4:50 handmade paper-cutout explainer (English + Chinese, captions, cover image). CPU-rendered with Pillow. |
| [`hype/`](hype/README.md) | **MobileGL hype reel**: a 3:33 beat-synced 1080p60 showreel with a synthesised soundtrack, rendered on the GPU through MobileGL itself. Also contains a short animated sting of the MobileGlues mark. |
