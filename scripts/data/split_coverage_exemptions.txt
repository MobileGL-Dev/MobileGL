#
#   [<Backend>:]<gtest pattern> <reason-class> <one-line reason>
#
# Reason classes:
#   mechanism       the case asserts a process-local mechanism or pins one arm by design
#                   (MGL_ITEST_MONOLITH_MECHANISM_FILTER in MG_IntegrationTest/CMakeLists.txt)
#   single-backend  the case belongs to the OTHER backend and skips on this one; scoped to this one
#   no-records      the workload never reaches a verb (answered from the caps mirror or the
#                   client's own error surface), so ScenarioFixture's armed split assertion
#                   (EmitSeq must advance) is red by construction
#   inproc-peek     reads server state through an in-process peek only an inproc arm can answer
#   pending-fix     red on a split arm today; the reason names the package or DEBTS.md row that
#                   fixes it, and the row goes when the case is registered (a stale row is an error)
#
# Evidence for every row: docs/Disaggregated/notes/p8/A.md (per-arm census, junit per case).
