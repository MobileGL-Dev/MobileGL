# THE VERIFY-SPLIT ENTRIES THAT HONESTLY NEVER ARM THE COMPARATOR, BY NAME.
#
# `MGPipe: verify armed` is latched at a process's FIRST FILL, so a process that reaches no verb
# never prints it. The lane's arm proof (.github/workflows/test.yml, integration-verify-split)
# used to allow that with a COUNT - "at least 850 of at least 1000 client logs carry the line" -
# which leaves the remainder unnamed: the lane could lose fifty arms, gain fifty skips, and the
# floor would not move. This file is the census instead, and split_log_paths.py's
# `verify-split-arming` mode is what reads it.
#
# THE RULE, PER ENTRY. Every verify-split-logs/*.client.log must either
#   (a) carry the arming line, or
#   (b) belong to an entry ctest reported SKIPPED - a gtest skip is a process that brought a
#       session up and left before any verb, and the skip set is DRIVER-DEPENDENT (a GitHub
#       runner's lavapipe/llvmpipe skips more or fewer cases than the host's), so naming those
#       would ratchet on the driver rather than on the comparator, or
#   (c) be named below.
#
# TWO-SIDED, the rule dualblock-expected-fatals.txt already rides (ID-119):
#   * an unlisted, unskipped entry that did not arm FAILS - a case stopped issuing a verb, or
#     the comparator stopped reaching it, and both are quieter lanes than they look;
#   * a LISTED entry that ARMED fails - remove the row in the commit that made it arm;
#   * a LISTED name with no client log in this run fails - the entry was renamed or filtered
#     out, and the row is an amnesty nobody asked for.
#   A listed entry that SKIPS on some driver is allowed and reported: that is (b) doing its job.
#
# HOW TO REFRESH (never by hand from a guess):
#   ctest --test-dir build-split -L '^integration-verify-split$' -j 6 \
#       --output-junit /tmp/verify-split.xml
#   python3 MobileGL/MG_IntegrationTest/Harness/split_log_paths.py verify-split-arming \
#       build-split/MobileGL/MG_IntegrationTest/verify-split-logs /tmp/verify-split.xml this-file
# and put the names it prints here, under the class they belong to.
#
# MEASURED ON THE HOST (WSL Arch + lavapipe, build-split, 1064 entries with a private log):
# 909 armed, 99 unarmed and skipped, 56 unarmed and named below.
